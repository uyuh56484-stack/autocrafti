# Auto Crafting Station 1.0.0

Полноценная версия мода для **Minecraft 1.21.1 + NeoForge 21.1.x**, Java 21.

## Возможности

- Новый блок «Автоматическая станция крафта» с собственной текстурой в индустриальном стиле.
- Обычный ПКМ (без Shift) открывает ванильный интерфейс верстака 3×3.
- Shift + ПКМ открывает GUI автокрафта: пять переключаемых профилей, матрица шаблона 3×3, просмотр результата, включение/выключение профиля и очистка шаблона.
- Каждый профиль хранит 9 предметов шаблона в BlockEntity NBT и переживает перезагрузку мира.
- Автокрафт работает по настоящим рецептам `minecraft:crafting` через RecipeManager, поэтому учитывает датапаки и рецепты других модов.
- Станция проверяет наличие всех ингредиентов и свободного места под результат и остатки крафта (например, пустые вёдра) до списания ресурсов.
- Внутренний буфер: 18 входных слотов и 9 выходных. Суммарная скорость обработки — до одного успешного крафта за 10 игровых тиков (если ресурсы и место в выходе доступны).
- Ввод с левой стороны блока и сверху; вывод с правой стороны и снизу. Стороны определяются относительно направления, в которое смотрит передняя часть блока.
- Прямое подключение соседних контейнеров: каждые 10 тиков станция забирает предметы из сундука слева и отправляет готовые предметы в сундук справа.
- NeoForge `Capabilities.ItemHandler.BLOCK` для воронок, труб и других модов, использующих ItemHandler; есть fallback для обычных `Container`-блоков.
- Предметы из входного/выходного буфера выпадают при разрушении блока.
- GUI отрисовывается собственной текстурой панели и поддерживает стандартные Minecraft tooltips/перемещение предметов.

## Управление

1. Поставь блок; сторона с лицевой панелью смотрит на игрока.
2. ПКМ — обычный верстак.
3. Shift + ПКМ — автокрафт.
4. Выбери один из пяти профилей сверху.
5. Положи ингредиенты рецепта в 3×3 слота шаблона. Слоты шаблона принимают по одному предмету; предметы возвращаются обычным кликом.
6. Нажми «Вкл. / Выкл.», чтобы включить выбранный рецепт. Очистка удаляет только шаблон выбранного профиля.
7. Включи профиль перед подачей материалов. Сундук слева станция опустошает только по предметам, которые указаны в активных шаблонах, чтобы не забивать буфер посторонними предметами. Можно также подавать ресурсы воронкой/трубой слева или сверху. Готовые предметы появятся в выходном буфере; станция отправит их в сундук справа или их можно извлекать справа/снизу через воронки и трубы.

**Важно о шаблонах:** шаблон задаёт точные предметы и расположение клеток. Станция сверяет его с действующим рецептом Minecraft. Она не создаёт предметы по произвольной схеме.

## Сборка локально

- Установи JDK 21.
- Установи Gradle 9.2.1.
- В корне проекта выполни:

```bash
gradle clean build --no-daemon
```

JAR будет в `build/libs/autocraftingstation-1.0.0.jar`.

## Сборка через GitHub Actions

1. Создай пустой репозиторий GitHub.
2. Распакуй ZIP и загрузи в репозиторий всё содержимое папки проекта (включая скрытую `.github`).
3. Открой **Actions** → workflow **Build Auto Crafting Station**.
4. Дождись зелёного статуса `Success`, открой запуск.
5. Внизу страницы в **Artifacts** скачай `AutoCraftingStation-1.0.0` и распакуй — внутри будет JAR.
6. Помести JAR в `mods` у клиента и сервера с Minecraft 1.21.1 NeoForge.

Для загрузки из терминала вместо веб-загрузки можно использовать:

```bash
git init
git add .
git commit -m "Add AutoCraftingStation"
git branch -M main
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

Workflow использует Java 21, Gradle 9.2.1 и NeoForge 21.1.267. Для модпака можно заменить `neo_version` в `gradle.properties` на установленную в сборке версию ветки 21.1.x.

## Проверка

Структура ресурсов, JSON-файлы и содержимое архива проверены локально. В среде подготовки отсутствует Gradle и нет сетевого доступа к Maven/Gradle-серверам, поэтому фактический `gradle build` и запуск Minecraft здесь выполнить не удалось. GitHub Actions предназначен для выполнения этой компиляции в доступной среде. Если CI выдаст ошибку API/версии, пришли полный лог сборки — он позволит исправить оставшееся несовпадение с выбранной версией NeoForge.
