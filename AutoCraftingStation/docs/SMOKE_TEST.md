# Игровой smoke-test после сборки

- [ ] Мод загружается на NeoForge 21.1.x / Minecraft 1.21.1 без ошибок регистрации.
- [ ] Блок виден в креативной вкладке Auto Crafting Station и выдаётся командой `/give @p autocraftingstation:crafting_station`.
- [ ] ПКМ открывает ванильный экран крафта, Shift+ПКМ — наш интерфейс.
- [ ] Можно заполнить/очистить шаблон каждого из пяти профилей и включать профили независимо.
- [ ] Профиль и включённое состояние сохраняются после перезахода.
- [ ] Пример: шаблон из 2 досок вертикально, подать нужные доски слева — палки появляются в выходе.
- [ ] Без полного набора ингредиентов крафт не выполняется.
- [ ] При заполненном выходе ингредиенты не списываются.
- [ ] Остатки рецептов (ведро/бутылка) не теряются.
- [ ] Сундук слева автоматически передаёт ресурсы в станцию.
- [ ] Сундук справа автоматически принимает готовые предметы.
- [ ] Воронка/труба на левой стороне вставляет ресурсы; воронка/труба на правой стороне извлекает готовые предметы.
- [ ] Стороны ввода/вывода корректно поворачиваются при повороте блока.
- [ ] При разрушении блока его содержимое выпадает.
